# Data Sources and Setup

The large raw datasets used in this project are not stored in this repository. This avoids duplicating externally maintained data and respects file-size and redistribution constraints.

## Required Raw Files

| Dataset | Expected filename | Source |
|---|---|---|
| Ofcom 4G LTE measurements (2025) | `4g-lte-2025-mobile-signal-measurement-data.csv` | [Ofcom mobile signal-strength measurement data](https://www.ofcom.org.uk/phones-and-broadband/coverage-and-speeds/mobile-signal-strength-measurement-data?language=en) |
| Ofcom 5G NR measurements (2025) | `5g-nr-2025-mobile-signal-measurement-data.csv` | [Ofcom mobile signal-strength measurement data](https://www.ofcom.org.uk/phones-and-broadband/coverage-and-speeds/mobile-signal-strength-measurement-data?language=en) |
| OpenCellID United Kingdom export (MCC 234) | `234_raw.csv` | [OpenCellID downloads](https://opencellid.org/downloads/) |

OpenCellID may require an account and API access token to download country-specific exports. Users should follow the current [OpenCellID server usage policy](https://wiki.opencellid.org/wiki/Server_usage_policy) and provide the required attribution.

## Google Earth Engine Sources

The following datasets are accessed directly through Google Earth Engine and do not need to be downloaded manually:

- GADM 4.1 administrative boundary data;
- Copernicus Sentinel-1 GRD;
- Copernicus Sentinel-2 Surface Reflectance Harmonized;
- ESA WorldCover 2021;
- WorldPop population data; and
- VIIRS monthly night-time-light data.

Google Earth Engine authentication and an enabled Cloud project are required for the extraction notebook.

## Recommended Directory Structure

Place the three manually downloaded files in the following Google Drive structure:

```text
MyDrive/
└── england-lte-5g-signal-prediction/
    └── data/
        └── raw/
            ├── ofcom/
            │   ├── 4g-lte-2025-mobile-signal-measurement-data.csv
            │   └── 5g-nr-2025-mobile-signal-measurement-data.csv
            └── opencellid/
                └── 234_raw.csv
```

## Data Notes

- The Ofcom data contain drive-test measurements collected along UK roads and do not provide uniform national sampling.
- The OpenCellID file represents crowdsourced cellular-infrastructure records and should not be interpreted as a complete inventory of operational base stations.
- Intermediate and final datasets are generated by running the notebooks in numerical order.
- Ofcom measurement counts are retained for label-reliability analysis but excluded from the predictor matrix to prevent target leakage.

## Redistribution

Before redistributing any downloaded or derived data, users should review the current terms and attribution requirements of each provider. The source websites and their terms remain authoritative.
